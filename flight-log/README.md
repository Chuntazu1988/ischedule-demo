# יומן טיסות – הוראות הקמה

האפליקציה עובדת בלי Claude. הנתונים נשמרים ב-Firebase (שירות חינמי של Google), ואפשר להיכנס מכל טלפון עם אימייל וסיסמה. כל משתמש רואה רק את הטיסות של עצמו.

צריך חשבון Google. ההקמה לוקחת בערך 15 דקות, והיא חד-פעמית.

## שלב 1 – יצירת פרויקט ב-Firebase
1. נכנסים ל-https://console.firebase.google.com ולוחצים **Create a project** (או **Add project**).
2. נותנים שם (למשל `flight-log`). את Google Analytics אפשר לכבות. לוחצים **Create**.

## שלב 2 – הפעלת התחברות ומסד נתונים
1. בתפריט הצד: **Build ← Authentication ← Get started**. בלשונית **Sign-in method** בוחרים **Email/Password**, מפעילים (Enable) ושומרים.
2. בתפריט הצד: **Build ← Firestore Database ← Create database**. בוחרים מיקום קרוב (למשל `europe-west` או `me-west1`) ו-**Start in production mode**.
3. בתוך Firestore נכנסים ללשונית **Rules**, מוחקים את מה שיש שם ומדביקים את התוכן של הקובץ `firestore.rules`. לוחצים **Publish**.
   זה השלב שדואג שכל אחד יראה רק את הנתונים שלו.

## שלב 3 – חיבור האפליקציה
1. בעמוד הראשי של הפרויקט לוחצים על הסמל `</>` (**Web**) ונותנים שם לאפליקציה. אין צורך ב-Firebase Hosting בשלב הזה.
2. תקבל קטע קוד עם `firebaseConfig`. מעתיקים משם את ארבעת הערכים (`apiKey`, `authDomain`, `projectId`, `appId`) לקובץ `firebase-config.js`, במקום ה-`PASTE_...`.

## שלב 4 – העלאה לאינטרנט (כדי לקבל קישור)
הדרך הכי פשוטה:
1. נכנסים ל-https://app.netlify.com/drop (אפשר להירשם בחינם).
2. גוררים לשם את **כל תיקיית `flight-log`**.
3. מקבלים קישור (כתובת `.netlify.app`). את הקישור הזה אפשר לשלוח לכל אחד.

אחרי שיש קישור, צריך להוסיף אותו ל-Firebase:
**Authentication ← Settings ← Authorized domains ← Add domain**, ולהוסיף את הכתובת (בלי `https://`, למשל `my-flights.netlify.app`).

## שימוש
- פותחים את הקישור בטלפון, יוצרים חשבון (אימייל וסיסמה) וכותבים את השם.
- ב-iPhone: Safari ← שיתוף ← **הוסף למסך הבית**. ב-Android: Chrome ← תפריט ← **הוסף למסך הבית**.
- בטלפון חדש נכנסים עם אותו אימייל וסיסמה, והכול שם.
- האפליקציה עובדת גם בלי אינטרנט. טיסות שהוזנו מסתנכרנות כשהחיבור חוזר.

## עלות
החבילה החינמית של Firebase (Spark) מספיקה בהרבה לשימוש של צוות. אין צורך בכרטיס אשראי.
