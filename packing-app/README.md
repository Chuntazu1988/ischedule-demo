# PackPal – אפליקציית אריזה לטיול

קובץ אחד (`index.html`), בלי התקנות. פותחים בדפדפן (נייד או מחשב) וזהו.

מה היא עושה:
- מזינים יעד + תאריכים + פעילויות מתוכננות.
- שולפת תחזית מזג אוויר מ-Open-Meteo (חינמי, בלי מפתח). אם הטיול רחוק יותר מ-16 יום – ממוצע מאותם תאריכים בשנה שעברה.
- בונה רשימת אריזה מותאמת (קור/חום/גשם/רוח + בגד ים, נעלי הליכה, ציוד סקי וכו').
- צ'ק ליסט עם אנימציות, התקדמות, קונפטי, הוספה/מחיקה של פריטים, שיתוף בוואטסאפ.
- הכול נשמר בטלפון (localStorage).
